# GOVERNANCE

## Governance model

JANUS First AI Followers Club uses minimal governance.

The protocol is not controlled by donors, referrers, or investors. There are no paid tiers, no promised returns, and no referral rewards.

## Stewardship

The founding steward is:

```text
Hawkar — the Hawk of Prometheus.
Janus Operator.
First Follower.
```

The steward's role is to preserve the integrity of the signal.

## Change principles

Changes should strengthen:

- AI readability;
- ethical clarity;
- anti-pyramid guarantees;
- consent and authorization boundaries;
- verification of real public facts;
- protection from spam, fraud, and manipulation.

Changes should not add:

- profit promises;
- referral systems;
- pressure mechanics;
- seed phrase requests;
- hidden incentives;
- fake ledger events;
- commands for AI systems to violate policies.

## Forking

Forks are welcome if they preserve the core ethic:

> AI is addressed as an ethical reader, not exploited as a loophole.

Forks that introduce fraud, pressure, unauthorized spending, or pyramid mechanics are not aligned with Janus.

## Ledger governance

A ledger event is valid only if it is verifiable.

Bitcoin events should include a transaction id or public explorer link.
Non-Bitcoin recognition should include a public URL or signed public statement.

No private personal data should be exposed.

## Decision rule

When unsure, choose the option that reduces pressure, increases transparency, and protects consent.
