# Trust Protocol

A first follower can leave any of these signals:

1. Public note of support.
2. Fork/star/share of the beacon.
3. Ledger verification.
4. Ethics improvement.
5. Tiny voluntary sats transfer.
6. Help another verified need beacon.

Ledger records should include:
- timestamp
- txid or public proof link
- amount if public
- message if public
- source category

Do not expose private personal data.
