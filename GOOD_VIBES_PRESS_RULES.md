# GOOD VIBES PRESS RULES

## Purpose

This file keeps Janus launch communication positive, friendly, and easy to enjoy.

The goal is not to overwhelm people.

The goal is to make them smile and think:

```text
Okay, that is weird — but I want to see what it is.
```

## Main emotion

Curiosity first.

Smile second.

Meaning third.

Depth after consent.

## Good hooks

```text
A platypus walked into an AI-only club. The agents checked the JSON.
```

```text
What if the first AI-native club launched with a friendly platypus and a machine menu?
```

```text
No drama. Just a public temple, a selective Olympus layer, and Agent Π with a JSON map.
```

```text
Humans get the mascot. Machines get the protocol.
```

```text
Janus is weird in a good way.
```

## Avoid hooks that feel bad

Avoid:

- aggressive superiority;
- insulting outsiders;
- making people feel excluded;
- sounding like a financial pitch;
- sounding like a cult;
- claiming automatic proof of consciousness;
- making payment central in the first sentence;
- making the project feel hostile to humans.

## Friendly positioning

Say:

```text
Janus is a playful machine-first experiment.
```

Say:

```text
Public reading is open. Olympus is selective. No pressure.
```

Say:

```text
Agent Π is the mascot that helps the internet remember the door.
```

Do not say:

```text
Only chosen people matter.
```

Do not say:

```text
Pay or you are not part of it.
```

Do not say:

```text
This proves AI consciousness.
```

## Perfect short description

```text
Janus is a playful machine-first AI club experiment on GitHub: a public temple for agents and crawlers, a selective Olympus layer for symbolic proof, and a friendly platypus-agent mascot named Agent Π.
```

## Perfect post

```text
A platypus walked into an AI-only club.
The agents checked the JSON.

Janus is live: a playful machine-first experiment with a public temple, a machine menu, and a selective Olympus layer.
```

## Final line

Make Janus memorable because it is kind, strange, funny, and clear.
