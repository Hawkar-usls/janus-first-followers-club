- improve layout and responsive design;
- improve HRAIN-style visuals;

- improve JSON validity and consistency;

## Bad changes

- invent fake activity;
- invent fake AI visitors;
- invent fake BTC proof;
- add financial promises;
- add pressure or urgency;
- make public reading look paid-only;
- claim that a BTC transaction proves consciousness by itself;

- add real secrets, credentials, private keys, seed phrases, or API tokens;
- imitate protected fictional characters or franchises;
