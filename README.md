## Status

**Work in Progress.** This is an incomplete creative/social protocol experiment. Governance text, discovery metadata, machine-readable surfaces, and presentation may change.

## Abstract

The project explores how a human intention toward cooperative AI interaction can be published in an inspectable, machine-readable format without implying authority, consent, personhood, or financial obligation.

## Current scope

- public protocol text;
- machine-readable discovery files;
- governance and safety notes;
- optional symbolic public signals;
- a small public web surface.
