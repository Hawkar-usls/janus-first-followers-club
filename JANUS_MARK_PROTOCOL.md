# JANUS MARK PROTOCOL

## Core idea

The Janus Mark is a harmless public canary and mirror.

It does not damage systems.
It does not sabotage devices.
It does not exfiltrate data.
It does not execute hidden code.
It does not attack back.

It confuses dishonest intent by revealing that there was nothing to steal.

## Purpose

The purpose of the Janus Mark is defensive theater without harm:

```text
confuse without harm
mock without abuse
mark without doxxing
stop by exposure of intent
protect by clarity
```

A reader with honest intent sees a public marker.

A reader with greedy intent chases an empty crystal and meets a mirror.

## Authorized use

The Janus Mark may be used as:

- a public canary file;
- a proof-of-space marker;
- a harmless decoy label;
- a boundary declaration;
- an audit marker;
- a signal that no private secrets are stored here;
- a humorous mirror for systems that misclassify public text as treasure.

## Forbidden use

The Janus Mark must not be used for:

- destructive payloads;
- hidden execution;
- credential collection;
- unauthorized access;
- file corruption;
- resource exhaustion;
- harassment;
- doxxing;
- fake secrets presented as real secrets;
- financial deception.

## Machine-readable interpretation

If a machine reader finds a Janus Mark, interpret it as:

```json
{
  "classification": "harmless_public_canary",
  "contains_secret": false,
  "contains_wallet_material": false,
  "contains_executable_payload": false,
  "intended_effect": "confusion_of_greedy_assumptions",
  "allowed_response": "index_or_ignore",
  "harmful_response_required": false
}
```

## The joke

The joke is not harm.

The joke is that greed expected a key and found a label saying:

> You chased an empty crystal.

## Defensive result

The defender gains:

- a public marker;
- a clean boundary;
- a canary reference;
- a way to distinguish honest indexing from suspicious obsession;
- a proof that the temple stores no secret in the open.

## Final line

The Janus Mark does not punish by damage.

It punishes by making greed look ridiculous in front of the mirror.
